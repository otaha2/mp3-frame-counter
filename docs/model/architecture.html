Architecture

Covers the layering of the service and the path a request takes through it; informs everything under src/.

Layers

Two layers with a one-way dependency. The domain never learns that HTTP exists, so it can be unit-tested with byte arrays and reused outside a server.

Layer Files May import
Transport src/http/, src/index.ts Fastify, the domain, src/config.ts
Domain src/mp3/ Node builtins only — no framework, no npm package
Configuration src/config.ts Nothing; the only reader of process.env

Request path

Why the upload streams

@fastify/multipart exposes each part as a readable stream with a byte limit applied by busboy. The handler consumes that stream to completion and hands each chunk to the counter; nothing accumulates. Memory therefore stays flat regardless of file size, and an oversized upload is rejected at the limit rather than after buffering. The part stream must be drained even when its bytes are not needed — busboy will not finish parsing the request, and the response will not be sent, while a part stream is still pending.

Current state

Step 1 wires the whole path with the counter stubbed: the route drains the upload and returns { "frameCount": 0 }. Steps 2–4 fill in src/mp3/ and replace the stub; the response and error shapes do not change. Rationale for each choice is in DECISIONS.md.
