Frame Walker — the checkpoint at step 7

A playable walkthrough that hands you the parser's job. Decode a header field by field, walk a file frame by frame to its end deciding where each one lands, then count a second file while its bytes are still arriving — waiting when a frame is incomplete, and waiting again when it is complete but not yet proven.

It is a check, not an introduction. Read steps 1 to 6 first and it will confirm what you understood and expose what you skimmed. Open it cold and it will teach you the same material the hard way. Ten minutes either way.

The two files it uses are not illustrations. test/docs/frameWalker.test.ts rebuilds both as real MP3 bytes and checks this project's own counter returns the offsets, lengths and totals the walkthrough teaches, so the page cannot drift from the code — decisions.md D22.
